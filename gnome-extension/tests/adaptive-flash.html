Dimmer adaptive test page

Click anywhere or press F to go fullscreen. Measurements are only meaningful in fullscreen.

Recommended baseline: one monitor, screen dim 10%, adaptive on, strength 50. Hide the Dimmer window first, or move it to another monitor.

Default mode cycle: white 4 s, 50% grey 5 s, black 6 s. Space pauses, H hides the HUD, 1-4 force a solid colour, [ / ] change the white area.

Other modes: ?mode=area (white-area sweep), ?mode=solid&color=%23ffffff, ?mode=manual. Add &hud=0 for calibration runs. ?dim=NN only changes the on-screen model, not Dimmer.

Watch it with the Dimmer Debug tab or gjs -m gnome-extension/tests/adaptive-watch.js.

The page switches brightness abruptly. Skip it if flashing content is a problem for you.
